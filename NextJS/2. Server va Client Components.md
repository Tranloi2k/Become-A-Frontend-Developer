# 2. Server Components vs Client Components

Đây là khái niệm **quan trọng nhất** khi làm Next.js App Router.

---

## 2.1 Tóm tắt

| | Server Component (mặc định) | Client Component (`"use client"`) |
|---|------------------------------|----------------------------------|
| Chạy ở đâu | Chỉ server | Server (SSR) + browser (hydration) |
| Bundle JS gửi client | Không (thường) | Có |
| `useState`, `useEffect` | ❌ | ✅ |
| `onClick`, browser APIs | ❌ | ✅ |
| `async` component | ✅ | ❌ (component async) |
| Truy cập DB/env secret trực tiếp | ✅ | ⚠️ chỉ qua API/action |
| Import Client Component | ✅ | ✅ |
| Import Server vào Client | ❌ | ❌ |

**Mặc định mọi file trong `app/` là Server Component** trừ khi có `"use client"` ở đầu file.

---

## 2.2 Tại sao tách hai loại?

1. **Giảm JavaScript** gửi xuống browser → tải nhanh hơn.
2. **Fetch data gần nguồn** — trên server, không lộ token/secret.
3. **SEO** — HTML đã có nội dung khi crawl.

SPA React thuần: toàn bộ logic + fetch ở client → bundle lớn, waterfall request.

---

## 2.3 Composition pattern (khuyến nghị)

Đặt **Server Component làm container**, nhúng **Client Component nhỏ** cho phần tương tác.

```tsx
// products/page.tsx — SERVER
export default async function ProductsPage() {
  const result = await getProducts(); // fetch trên server
  return (
    <>
      <h1>Products</h1>
      <ListProductsComponent products={result.products} /> {/* có thể server */}
      <ProductToolbar /> {/* CLIENT — filter UI */}
    </>
  );
}
```

```tsx
// product-toolbar.tsx — CLIENT
"use client";
export default function ProductToolbar() {
  const router = useRouter();
  // cập nhật URL searchParams khi đổi filter
}
```

**Anti-pattern:** đánh `"use client"` ở root layout/page chỉ vì một nút cần `onClick` → cả cây con thành client.

---

## 2.4 Truyền props Server → Client

- Chỉ truyền **dữ liệu serializable** (JSON-safe).
- Không truyền function từ server xuống client (trừ Server Actions — xem file 3).

```tsx
// ✅
<BuyNowButton product={{ id: "1", name: "Phone", price: 999 }} />

// ❌
<Child onFetch={async () => db.query()} />
```

---

## 2.5 Suspense và streaming

```tsx
<Suspense fallback={<Skeleton />}>
  <ProductToolbar />
</Suspense>
```

- Phần chậm (client search, sidebar) stream sau phần nhanh.
- `loading.tsx` = Suspense boundary tự động cho segment.

**Nova Shop:** `ProductsPage` bọc `ProductToolbar` và `ProductPagination` trong `Suspense`.

---

## 2.6 Khi nào bắt buộc Client Component?

| Use case | Ví dụ trong Nova Shop |
|----------|------------------------|
| Event handlers | `BuyNowButton`, `productForm` |
| React hooks | `useState`, `useRouter`, `useSearchParams` |
| Browser API | `localStorage`, `window.dispatchEvent` (cart badge) |
| Thư viện chỉ chạy client | Một số chart, map |
| `SessionProvider` | `app/providers.tsx` |

---

## 2.7 Server Component fetch data

```tsx
export default async function Page() {
  const res = await authFetch(`${API}/products`);
  const data = await res.json();
  return <List products={data.products} />;
}
```

- `fetch` trên server có thể cache (`next: { revalidate: 60 }`).
- Lỗi 401 → `unauthorized()` từ `next/navigation`.

---

## 2.8 Children pattern với Client wrapper

```tsx
// layout server
export default function Layout({ children }) {
  return <ShopShell>{children}</ShopShell>;
}

// ShopShell có thể là client nếu cần state navbar
// children vẫn có thể là server pages
```

---

## 2.9 Checklist chọn loại component

```
Cần useState / useEffect / onClick?
  → Có: "use client" (file nhỏ nhất có thể)
  → Không: giữ Server Component

Chỉ hiển thị data từ API?
  → Server Component + async

Form submit lên server?
  → Server Action + form (có thể không cần client)
```

---

## 2.10 Lỗi thường gặp

| Lỗi | Nguyên nhân |
|-----|-------------|
| "You're importing a component that needs useState..." | Import client hook trong server file |
| Hydration mismatch | HTML server ≠ client (random id, `Date.now()` trên render) |
| Secret lộ ra client | Dùng `NEXT_PUBLIC_` nhầm cho key bí mật |

**Quy tắc env:**

- `NEXT_PUBLIC_*` — lộ ra browser.
- Không prefix — chỉ server (`STRIPE_SECRET_KEY`, `AUTH_SECRET`).
