# 8. NextAuth v5 (Auth.js)

NextAuth v5 (`next-auth@5`) đổi tên ecosystem thành **Auth.js** — API gọn hơn, tích hợp App Router native.

Package Nova Shop: `"next-auth": "5.0.0-beta.29"`.

---

## 8.1 Cấu trúc file chuẩn

```text
auth.ts              # NextAuth({ providers, callbacks, events })
auth.config.ts       # authConfig (edge-safe — dùng trong middleware)
middleware.ts        # export default NextAuth(authConfig).auth
app/api/auth/[...nextauth]/route.ts  # export { GET, POST } handlers
app/providers.tsx    # <SessionProvider> (client)
```

**Tách `auth.config.ts`:** phần không cần Node APIs full → chạy trên Edge middleware.

---

## 8.2 Khởi tạo NextAuth

```ts
// auth.ts
import NextAuth from "next-auth";
import Credentials from "next-auth/providers/credentials";
import Google from "next-auth/providers/google";
import { authConfig } from "./auth.config";

export const { auth, signIn, signOut, handlers } = NextAuth({
  ...authConfig,
  secret: process.env.AUTH_SECRET ?? process.env.NEXTAUTH_SECRET,
  providers: [
    Google({ clientId: "...", clientSecret: "..." }),
    Credentials({ authorize(credentials) { ... } }),
  ],
  callbacks: { /* jwt, session, signIn */ },
  events: { signOut() { ... } },
});
```

| Export | Dùng ở đâu |
|--------|------------|
| `auth()` | Server Component, Route Handler — lấy session |
| `signIn` / `signOut` | Server Actions |
| `handlers` | `route.ts` API auth |

## 8.4 Session strategy: JWT

```ts
// auth.config.ts
session: {
  strategy: "jwt",
  maxAge: 24 * 60 * 60,
  updateAge: 12 * 60 * 60,
},
jwt: {
  maxAge: 30 * 24 * 60 * 60,
},
```

| | JWT session | Database session |
|---|-------------|------------------|
| Lưu trữ | Token signed | Bảng `sessions` |
| Scale | Dễ, stateless | Cần DB |
| Revoke realtime | Khó hơn | Dễ |

Nova Shop dùng **JWT** cho NextAuth; backend NestJS có session/token riêng trong cookie.

## 8.5 Providers

### Credentials

```ts
Credentials({
  async authorize(credentials) {
    const parsed = z.object({ email: z.string().email(), password: z.string().min(6) })
      .safeParse(credentials);
    if (!parsed.success) return null;

    const response = await login({ email, password }); // backend
    await setAuthCookies({ accessToken, refreshToken, userId });
    return { id: email, name: email };
  },
}),
```

- Return `null` → login fail.
- Return user object → tạo session.

### Google

```ts
Google({
  clientId: process.env.GOOGLE_CLIENT_ID!,
  clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
  authorization: {
    params: { prompt: "consent", access_type: "offline", response_type: "code" },
  },
}),
```

Callback `signIn` — khi `account.provider === "google"`:

```ts
async signIn({ user, account }) {
  if (account?.provider === "google") {
    const response = await googleAuthAction({ idToken: account.id_token! });
    await setAuthCookies({ ... });
    return true;
  }
  return true;
}
```

## 8.6 Callbacks quan trọng

### `authorized` (middleware)

Quyết định request có được vào route không — xem [6. Middleware.md](./6.%20Middleware.md).

### `jwt`

```ts
async jwt({ token, user, account }) {
  if (account && user) {
    return { ...token, accessToken: account.access_token, expiresAt: ... };
  }
  if (token.expiresAt && Date.now()/1000 > token.expiresAt) return null; // force logout
  return token;
}
```

### `session`

```ts
async session({ session, token }) {
  session.accessToken = token.accessToken;
  session.expiresAt = token.expiresAt;
  if (token.sub) session.user.id = token.sub;
  return session;
}
```

### Module augmentation TypeScript

```ts
declare module "next-auth" {
  interface Session {
    accessToken?: string;
    expiresAt?: number;
    nearExpiry?: boolean;
  }
}
```

## 8.7 Server Action login

```ts
"use server";
import { signIn } from "@/auth";
import { AuthError } from "next-auth";

export async function authenticate(prevState, formData: FormData) {
  try {
    await signIn("credentials", {
      email: formData.get("email"),
      password: formData.get("password"),
      redirectTo: formData.get("redirectTo")?.toString() ?? "/products",
    });
  } catch (error) {
    if (error instanceof AuthError) {
      if (error.type === "CredentialsSignin") return "Invalid credentials.";
    }
    throw error; // redirect throw — phải rethrow
  }
}
```

**Lưu ý:** `signIn` thành công thường **throw redirect** — không bọc hết trong catch generic.

## 8.9 Lấy session trên server

```tsx
import { auth } from "@/auth";

export default async function Page() {
  const session = await auth();
  if (!session?.user) redirect("/login");
}
```

## 8.10 Events

```ts
events: {
  async signOut() {
    await logout();        // backend
    await clearAuthCookies();
  },
},
```

Cleanup khi user chủ động logout.

## 8.11 NextAuth v4 → v5 khác biệt chính

| v4 | v5 |
|----|-----|
| `[...nextauth].js` config lớn | `auth.ts` + `auth.config.ts` |
| `getServerSession` | `auth()` |
| `useSession` vẫn có | `SessionProvider` tương tự |
| Docs next-auth.org | authjs.dev |

Đọc docs đúng phiên bản khi copy tutorial cũ.

## 8.12 Troubleshooting

| Triệu chứng | Kiểm tra |
|-------------|----------|
| Redirect loop login | `authorized` + `pages.signIn` |
| Google callback error | Redirect URI trong Google Console = `{ORIGIN}/api/auth/callback/google` |
| Session null trên server | `AUTH_SECRET` thiếu |
| Middleware không chạy | `matcher` exclude path |
