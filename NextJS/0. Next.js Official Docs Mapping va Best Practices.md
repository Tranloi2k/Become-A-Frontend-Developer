> Cập nhật theo Next.js **14–15** (App Router). Luôn đối chiếu: https://nextjs.org/docs/llms.txt

**Cách học bộ tài liệu:** Mỗi file (1–10) theo phong cách [5. Data Fetching](./5.%20Data%20Fetching%20va%20Cache.md) — mục lục, vấn đề, luồng Nova, FAQ. File **0** dùng để **tra cứu nhanh** khi review code hoặc phỏng vấn.

## 2. Bảng so sánh tổng hợp theo kỹ thuật

### 2.1 App Router & routing

| | Best practice (Next.js Docs) | Nova Shop | Đánh giá |
|---|------------------------------|-----------|----------|
| Tổ chức route | `app/` + route groups khi cần layout khác nhau | `(shop)`, `(dashboard)` + `ShopShell` | ✅ Phù hợp |
| Dynamic `params` | `await params` (v15 Promise) | `[slug]/page.tsx` dùng đúng pattern | ✅ |
| Filter state | `searchParams` trên URL | `parseProductFilters` + toolbar client | ✅ Chuẩn |
| `loading.tsx` | Mỗi segment chậm nên có skeleton | Chủ yếu `<Suspense>` inline | ⚠️ Nên thêm `loading.tsx` cho `/products` |
| `error.tsx` | Error boundary theo segment | `(shop)/products/error.tsx`, … | ✅ Có thể thêm `loading.tsx` |
| Static paths | `generateStaticParams` + `dynamicParams` | `[slug]/page.tsx` ISR 60s | ✅ |

### 2.2 Server vs Client Components

| | Best practice | Nova Shop | Đánh giá |
|---|---------------|-----------|----------|
| Mặc định Server | Page/layout fetch trên server | `products/page.tsx` async + `getProducts` | ✅ |
| Client leaf nhỏ | Chỉ `"use client"` khi cần hook/event | `productForm`, `navbar`, `BuyNowButton` | ✅ |
| Truyền props | Serializable only | Product object plain JSON | ✅ |
| Navbar data | Truyền từ layout server hoặc RSC children | Client `navbar` gọi `getCart()`, `getUser()` | ⚠️ Thêm round-trip; docs khuyên fetch ở layout server |

### 2.3 Server Actions

| | Best practice | Nova Shop | Đánh giá |
|---|---------------|-----------|----------|
| Định nghĩa | `"use server"` ở file `lib/actions` hoặc `services` | `cart.ts`, `products.ts`, `actions.ts` | ✅ |
| Form | `action={fn}` + `useActionState` cho lỗi | `authenticate` + `useFormState` pattern | ✅ |
| Sau mutation | `revalidatePath` / `revalidateTag` | `revalidateCartPaths()` | ✅ Path; chưa dùng Tag |
| Bảo mật | Coi Action như **public HTTP POST**; validate + auth trong action | `authFetch` trong services | ✅ Cốt lõi đúng |
| Config | `serverActions.allowedOrigins` nếu proxy | Chưa cấu hình | ⚠️ Production behind proxy |
| Gọi từ client | OK nhưng tránh lạm dụng cho read-heavy | Navbar gọi `getCart` action | ⚠️ Nên read qua RSC |

**Trích docs:** *"You should still treat Server Actions as public HTTP endpoints."* — https://nextjs.org/blog/next-15

### 2.4 Route Handlers

| | Best practice | Nova Shop | Đánh giá |
|---|---------------|-----------|----------|
| Webhook | `request.text()` + verify signature | Stripe `constructEvent` trên raw body | ✅ Chuẩn doc |
| Checkout | Route Handler cho third-party / `fetch` từ client | `/api/checkout`, `/api/checkout/cart` | ✅ |
| Cùng segment với `page` | Không được `route.ts` + `page.tsx` cùng folder | Tách `app/api/*` | ✅ |
| GET caching (v15) | GET handlers **dynamic by default**; opt-in `force-static` | Checkout POST only | ✅ N/A |
| Segment config | `dynamic` / `revalidate` / `fetchCache` / `runtime` literal trong route file | Shop: `force-dynamic` + `default-no-store`; home: `revalidate: 60`; API Stripe: `runtime: nodejs` | ✅ Chi tiết [file 5 §13](./5.%20Data%20Fetching%20va%20Cache.md#13-route-segment-config--vai-trò--mối-liên-hệ-cache) |

### 2.5 Data fetching & cache

| | Best practice | Nova Shop | Đánh giá |
|---|---------------|-----------|----------|
| Authenticated fetch | Không cache chung user-specific | `authFetch`, `cache: 'no-store'` implicit | ✅ |
| Public catalog | `next: { revalidate: N }` hoặc tag | `getProducts({ authenticated: false })` có option nhưng page luôn auth | ⚠️ Catalog bắt login — product decision |
| Invalidate | `revalidateTag` cho nhóm fetch cùng tag | Chỉ `revalidatePath` | ⚠️ Scale lớn nên thêm tags |
| `refresh()` | Refresh current route sau action | Không dùng — dùng revalidatePath | ✅ Đủ cho case hiện tại |
| Request memoization | Cùng request, cùng fetch dedupe | Một page một lần `getProducts` | ✅ |

### 2.6 Middleware

| | Best practice | Nova Shop | Đánh giá |
|---|---------------|-----------|----------|
| Vai trò | Optimistic check: cookie có / không | NextAuth `.auth` + cookie backend | ✅ |
| Không thay auth đầy đủ | **Luôn verify lại** trong Server Component/Action | `authFetch` + `unauthorized()` | ✅ Đúng guide |
| Matcher | Hẹp, tránh static assets | Exclude `api`, `_next`, files | ✅ |
| Logic nặng | Tránh DB trong middleware | Chỉ đọc cookie | ✅ |
| Auth chính thức | Có thể dùng Proxy (mới) hoặc middleware | Middleware NextAuth | ✅ |

**Trích [Authentication Guide](https://nextjs.org/docs/app/guides/authentication):** Middleware chỉ nên là lớp đầu; quyền truy cập dữ liệu phải kiểm tra gần data layer.

### 2.7 Authentication (tổng hợp)

| | Best practice | Nova Shop | Đánh giá |
|---|---------------|-----------|----------|
| Một nguồn session | Auth.js session HOẶC app JWT, tránh drift | **Dual:** NextAuth JWT + backend cookies | ⚠️ Cần thiết vì API NestJS riêng; phức tạp hơn doc |
| Token storage | HttpOnly cookie | `access_token`, `refresh_token` HttpOnly | ✅ |
| Refresh | Short access + refresh rotation backend | `refreshTokens()` trong `auth-tokens.ts` | ✅ |
| OAuth | Auth.js provider + backend verify id_token | Google → `POST /google` | ✅ Pattern BFF phổ biến |
| `userId` query | Lấy từ session/token server-side | `GET /cart?userId=` từ cookie | ⚠️ Backend nên derive từ JWT |
| Middleware only | Không đủ | Middleware + `authFetch` | ✅ |
| SessionProvider | Client khi cần `useSession` | `providers.tsx` | ✅ |

### 2.8 NextAuth v5 cụ thể

| | Best practice | Nova Shop | Đánh giá |
|---|---------------|-----------|----------|
| Tách `auth.config` | Edge-safe config cho middleware | `auth.config.ts` + `auth.ts` | ✅ |
| Callback trùng | Một nơi jwt/session | Trùng jwt/session ở `auth.ts` và `auth.config` | ⚠️ Nên gom tránh lệch logic |
| `AUTH_SECRET` | Bắt buộc production | `AUTH_SECRET ?? NEXTAUTH_SECRET` | ✅ |
| Credentials | `authorize` gọi backend, không lưu password | `POST /login` + `setAuthCookies` | ✅ |

## 4. Khuyến nghị cải thiện Nova Shop (theo thứ tự ưu tiên)

1. **Gom callback** `jwt`/`session` — chỉ trong `auth.ts` hoặc chỉ `auth.config.ts`.
2. **Navbar:** truyền `cartCount` / `user` từ layout Server Component thay vì client gọi Server Actions.
3. **Backend cart:** bỏ `userId` query param — lấy từ JWT claims.
4. **Thêm `error.tsx`** cho `(dashboard)/products` và `cart`.
5. **`revalidateTag('cart')`** khi fetch cart/products dùng chung tag.
6. **Catalog public:** nếu business cho phép, bỏ bắt buộc login `/products` (middleware) — giữ auth cho cart/checkout.
7. **Webhook Stripe:** gọi API NestJS ghi đơn sau `checkout.session.completed`.
8. **`metadataBase`:** đổi sang domain thật trong `app/layout.tsx`.
9. **Production:** `serverActions.allowedOrigins` nếu deploy sau reverse proxy.
